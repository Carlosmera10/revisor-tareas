# Revisor de Proyectos y Tareas

Gestor de proyectos y tareas con prioridades, etiquetas, sub-tareas, vista Kanban, tareas recurrentes, acciones masivas y avisos.

**App:** https://carlosmera10.github.io/revisor-tareas/

- Se puede instalar como aplicación desde Chrome y funciona sin conexión.
- Los datos se guardan solo en el navegador de cada equipo (no se suben aquí). Usa «Exportar datos» para hacer copias de seguridad.
